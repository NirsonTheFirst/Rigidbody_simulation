# Rigidbody Simulation

ПР №3 по моделированию физических процессов.

## Как запустить

Нужны Visual Studio 2022 с поддержкой C++ и [SFML 3.1.0](https://www.sfml-dev.org/download/sfml/3.1.0/) для Visual C++ 2022 x64.

1. Распаковать SFML в `libs\SFML`. Внутри должны быть папки `bin`, `include` и `lib`.
2. Открыть `Rigidbody_simulation.sln`, выбрать **Release / x64** и нажать **F5**.

## Управление

- Пробел - сделать один шаг.
- R - вернуть объект на старт.
- 0 - показать все три режима.
- 1 - обычная проверка.
- 2 - CCD.
- 3 - multi-rate.
- Esc - выйти.

После шага контур показывает, где объект был в начале. Зелёный означает, что столкновение обнаружено, красный показывает пролёт сквозь стенку.

Скорость, частоты и коэффициент восстановления можно поменять в `physics.h`.
