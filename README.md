# Rigidbody Simulation

ПР №3 по моделированию физических процессов.

## Сборка

Нужны Visual Studio 2022 с компонентом «Разработка классических приложений на C++» и [SFML 3.1.0](https://www.sfml-dev.org/download/sfml/3.1.0/) для Visual C++ 2022 x64.

1. Распаковать SFML в `libs\SFML`, чтобы внутри были папки `bin`, `include` и `lib`.
2. Открыть `Rigidbody_simulation.sln`, выбрать **Release / x64** и нажать **F5**.

## Управление

- **1** - Discrete, проверка столкновений в конце шага на 60 Гц.
- **2** - Continuous (CCD), поиск момента столкновения внутри шага.
- **3** - Multi-rate, обычные круги на 60 Гц и снаряды на 240 Гц.
- **P** - пуск или пауза.
- **Пробел** - один шаг на паузе.
- **S** - переключить скорость показа между 1 и 1/16.
- **G** - включить или выключить гравитацию.
- **R** - вернуть сцену в начальное состояние.
- **Esc** - выход.

При выборе режима сцена запускается с одинаковыми начальными условиями на паузе. Скорость снаряда, частоты и количество кругов можно поменять в `settings.h`.

## Замеры

**Physics avg** показывает среднее время расчёта физики на кадр без отрисовки. **240 Hz steps** показывает число подшагов за последний кадр с расчётом в режиме Multi-rate.
